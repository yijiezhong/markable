开始使用

  • 打开文档：Finder 里双击 .md、把文件拖到 Dock 图标，或 ⌘O；⇧⌘O 快速打开（按文件名过滤当前目录）。
  • 标签页：所有文档共用一个窗口，每个文件一个标签；重复打开会切到已有标签。⌘N 新建标签、⌘W 关闭当前标签。
  • 只读、离线：Markable 不修改文件，不发起网络请求；代码高亮、表格、公式、图表全部在本地渲染。
  • 恢复：下次启动自动回到上次阅读的文档与位置。

阅读

  • 翻屏：空格 下一屏、⇧空格 上一屏（PageDown / PageUp 同效）。
  • 缩放：⌘+ 放大、⌘− 缩小、⌘0 实际大小、⌘9 缩放至窗口大小。
  • 支持的语法：CommonMark + GFM（表格、任务列表、删除线、自动链接）；扩展：脚注、callout（> [!NOTE]）、AI 标注、交叉引用、目录页、数学（KaTeX）、Mermaid 图（15 种自研渲染器 + 兜底渲染）、图片、水平线、引用内围栏代码块。
  • 表格：渲染为真正的网格（NSTextTable），列宽自适应；导出 PDF 时跨页表格会在后续页面重复表头。
  • 引用：整块灰底 + 左侧竖线，空行分隔的多段引用每段都有竖线；复制时竖线还原为 >。
  • 代码：围栏 / 波浪线 / 撇号围栏，按语言高亮；可选行号（复制时自动剔除）。

导航

  • 侧边栏（⌘J 显示/隐藏）两个面板：
    • 大纲 ⌘K：标题层级，点击跳转。
    • 文件 ⌘L：同目录下的其它 Markdown 文件，点击打开。
  • 标题：⌘↑ / ⌘↓ 依次跳到上一个 / 下一个标题；段落：⌥⌘↑ / ⌥⌘↓，每次约前进一屏。
  • 滚动：⌘↖ 顶部、⌘↘ 底部。

查找

  • ⌘F 文档内查找（面板里可切「区分大小写 / 整词 / 正则」）；⌘G / ⇧⌘G 上下一个。
  • ⇧⌘F 在文件夹中查找（跨文件搜索）；⌥⌘F 使用系统查找面板。
  • ⌥⌘G 用当前所选内容查找。

显示与版式

  • 主题与版式（菜单与工具栏各有一份）：主题为跟随系统 / 浅色 / 深色；版式为 6 套模板（舒适阅读、学术论文、技术文档等）。
  • 字号与排版菜单：字体、行距 / 段间距、自动折行、首行缩进、标题编号、代码行号。
  • 页边距 / 页眉 / 页脚 / 目录页：在「设置」（⌘,）的「导出」页里调整；纸张固定 A4。

复制

复制（⌘C、右键、拖拽、服务菜单）只输出可见内容：

  • 语法标记（#、**、反引号、链接括号、代码围栏、front matter）不会进入剪贴板；
  • 引用竖线还原为 >，嵌套引用保留原层数（> >）；
  • 表格按行复制成制表符分隔（TSV），可直接粘进 Excel / Numbers / 飞书表格；
  • 图片替换为 [图片: alt]，Mermaid 替换为 [Mermaid: 源码摘要]，公式替换为 [公式]；
  • 代码行号、标题编号自动剔除。

导出

  • PDF 有两条通道：本机装了 md2pdf 时优先用它（交付级版式、书签、页码）；否则用内置 A4 分页（跨页表格重复表头、接缝单线）。
  • md2pdf 的版式由它自己的样式决定，不读取「PDF 选项」里的纸张 / 页眉页脚 / 目录页；想用自己的这些设置，在「PDF 选项」里勾选强制使用内置导出。
  • HTML：含样式 / 纯内容两种；本地图片内联为 data: URI（单文件可移植，体积随图片增长），javascript: 等危险链接会被过滤成纯文字。
  • 图片：按 A4 页逐页导出 PNG。
  • 批量导出：对一个文件夹递归导出 PDF / HTML / PNG，失败项会在结尾汇总。
  • 分享：用系统分享面板分享临时 PDF。
  • 入口：工具栏的「导出」下拉把上面这些收在一起；页眉 / 页脚 / 目录页在「设置 → 导出」里调。

文档体检

  • 菜单「编辑 → 文档体检」检查：未定义的链接引用、未被引用的定义、脚注引用/定义配对、标题层级跳跃等。
  • 点击条目跳到对应行；0 处时显示「未发现问题」。

命令与自动化

  • markable://open?path=/绝对路径/文档.md 打开文档。
  • markable://export?path=…&output=…&format=pdf|html 直接导出。
  • 命令行：open -a Markable 文档.md。

已知限制

  • Mermaid 主题：%%{init: {"theme": …}}%% 会被解析出来，但不改变配色——渲染主路径由第三方库负责，它不提供配色注入；自研渲染器跟随系统外观。
  • md2pdf 通道的版式：纸张 / 页边距 / 页眉页脚 / 目录页由 md2pdf 决定，需要时勾选「强制使用内置导出」。
  • PDF 文本层：内置通道导出的 PDF 里，部分汉字会以康熙部首形式写入文本层（显示正常，复制出来个别字可能不同）。
  • 复制时的空行：front matter / 链接定义等整段隐藏内容被删掉后，其前后若原本有多个空行，最多吸收到剩一个。
  • 表格跨页：表头重复只在「本页放得下至少一整行」时生效，否则宁可不重复也不切断行。
  • 5MB 以上文档：块级语法扫描约 0.6 秒，超大文档首屏会明显变慢。
